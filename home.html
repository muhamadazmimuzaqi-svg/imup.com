Tanya Jawab Singkat

HTML (HyperText Markup Language) adalah bahasa penanda untuk menyusun isi halaman web: judul, paragraf, gambar, tabel, dan tautan.

CSS mengatur tampilan: warna, ukuran huruf, jarak, tata letak, sampai animasi, sehingga isi halaman terlihat menarik.

Frameset membagi satu jendela menjadi beberapa bagian. Menu, header, dan footer tetap diam, sementara isi di sebelah kanan berganti-ganti.

Unggah semua file ke layanan hosting, pastikan nama folder dan file sama persis, lalu buka alamatnya dari browser.
